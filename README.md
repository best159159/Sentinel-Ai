## ❓ 1. โปรเจกต์คืออะไร? (What is Sentinel AI?)

**Sentinel AI** คือแพลตฟอร์ม และระบบเฝ้าระวังภัยพิบัติรวมถึงเหตุฉุกเฉินระดับชุมชน ขับเคลื่อนด้วยพลังของ AI ที่จะช่วยคัดกรอง วิเคราะห์ และประเมินความรุนแรงของสถานการณ์ ทำให้ผู้ใช้งานสามารถรับมือได้อย่างรวดเร็ว เช่น อุบัติเหตุรถชน, ไฟไหม้, น้ำท่วม, อาชญากรรม ฯลฯ ช่วยให้ทุกคนในพื้นที่ตื่นตัวและหลีกเลี่ยงพื้นที่เสี่ยงได้ทันท่วงที

## ✨ 2. ฟีเจอร์มีอะไรบ้าง? (Key Features)

- 🗺️ **Real-Time Map & Heatmap (แผนที่เหตุการณ์ตามเวลาจริง):** ดูภาพรวมเหตุการณ์พร้อมแสดงจุดเกิดเหตุ (Markers) และแบ่งสีตามระดับความรุนแรง
- 🤖 **AI Incident Analysis (วิเคราะห์สถิติและการเกิดเหตุด้วย AI):** ใช้ความสามารถของ OpenAI ในการประเมินระดับความรุนแรง แยกประเภทเหตุการณ์ และแนะนำวิธีการรับมือเบื้องต้นทันทีที่ได้รับแจ้ง
- 📸 **Smart Reports (ระบบรายงานเหตุการณ์อัจฉริยะ):** แจ้งเหตุง่ายๆ ด้วยการอัปโหลดรูปภาพ ระบบจะดึงตำแหน่งพิกัดอัตโนมัติ และให้ AI ช่วยเติมข้อความหรือจัดหมวดหมู่ลดภาระผู้แจ้ง
- 🚨 **Proximity Alerts (ระบบแจ้งเตือนเข้าใกล้พื้นที่เสี่ยง):** แจ้งเตือนผู้ใช้แบบเรียลไทม์ (แจ้งเตือนเด้งเตือนทันที) เมื่อเดินทางเข้าใกล้พื้นที่เกิดเหตุในรัศมีที่กำหนด
- 📰 **National Intelligence & News:** ฟีดติดตามข่าวสารรอบตัว ข่าวด่วน และประกาศเตือนภัยจากแอดมินหรือหน่วยงานที่เกี่ยวข้อง
- 📊 **Analytics & Admin Dashboard:** ระบบจัดการหลังบ้านพร้อมกราฟแสดงสถิติ สำหรับผู้ดูแลระบบ เพื่อดูแนวโน้มต่างๆ ในเชิงลึก
- 💬 **Community Chat (ระบบแชทชุมชน):** ช่องทางเพื่อพูดคุย กระจายข่าวสาร หรือสอบถามสถานการณ์จริงระหว่างคนที่อยู่ในพื้นที่

## 🛠️ 3. ใช้เทคโนโลยีอะไร? (Tech Stack)

โปรเจกต์นี้ทำงานในรูปแบบ Full-Stack โดยใช้เทคโนโลยีร่วมสมัยเพื่อประสบการณ์ที่ดีและการรองรับการขยายตัว (Scalability):

### 🎨 ฝั่งหน้าบ้าน (Frontend)
- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Maps:** [Leaflet](https://leafletjs.com/) (ใช้งานผ่านไลบรารี React-Leaflet) และระบบของ Mapbox
- **UI Animations:** [Framer Motion](https://www.framer.com/motion/) ทำให้แอนิเมชันลื่นไหล
- **Charts:** [Recharts](https://recharts.org/) (สำหรับการทำ Data Visualization)

### ⚙️ ฝั่งหลังบ้าน (Backend & Database)
- **Server:** Node.js & Express.js
- **Database:** PostgreSQL ร่วมกับ ORM อย่าง Prisma (หรือสลับเป็น SQLite ในช่วงการพัฒนา)
- **Real-Time:** [Socket.io](https://socket.io/) (รองรับ WebSockets ดึงพิกัด ข่าวสาร และแจ้งเตือนรวดเร็ว)
- **AI Integration:** OpenAI API 
- **Image Storage:** Cloudinary (จัดการรูปภาพต่างๆ ที่แนบตอนแจ้งเหตุ)
- **Authentication:** ระบบ Login/Register โดยใช้ JWT (JSON Web Tokens) ควบคู่กับ bcryptjs

## 🚀 4. รันยังไง? (How to Run Locally)

หากต้องการนำโค้ดไปรันเพื่อทดสอบหรือพัฒนาต่อบนเครื่องของคุณ สามารถทำได้ตามขั้นตอนนี้:

### Step 1: Clone Project & เข้าไปในโพลเดอร์
```bash
git clone <repository_url>
cd sentinel-ai-vibehack
```

### Step 2: ติดตั้ง Dependencies ทั้งหมด
โปรเจกต์นี้มีสคริปต์อัตโนมัติช่วยติดตั้ง Packages ของฝั่ง Root, Frontend และ Backend ให้พร้อมกัน:
```bash
npm run install:all
```
*(สคริปต์นี้ตั้งค่า `--legacy-peer-deps` ไว้เรียบร้อยแล้ว เพื่อจัดการความขัดแย้งของ React Versions)*

### Step 3: ตั้งค่า Environment Variables (ตัวแปรสภาพแวดล้อม)
ระบบต้องใช้ Configuration บางส่วนเพื่อติดต่อ Database และ API:
1. เข้าไปที่โฟลเดอร์ `backend/` หารูปแบบไฟล์ `.env.example` แล้วก็อปปี้มาสร้างเป็นไฟล์ชื่อ `.env` เติมค่าให้ครบ เช่น Database URL หรือ Cloudinary Keys
2. ทำเช่นเดียวกันในฝั่งโฟลเดอร์ `frontend/` (อาจจะเป็นไฟล์ชื่อ `.env.local.example` ให้ก็อปเป็น `.env.local` หรือปรับแก้ไฟล์เดิม)
3. รันระบบก็ยังไม่สมบูรณ์ หากต้องการใช้ฟีเจอร์ AI ต้องใส่ `OPENAI_API_KEY` ด้วย

### Step 4: เริ่มรันโปรเจกต์ (Start the Dev Server)
เมื่อเตรียมทุกอย่างเสร็จแล้ว อยู่ที่โฟลเดอร์นอกสุดรันคำสั่ง:
```bash
npm run dev
```
🎉 ระบบจะรัน **Backend** และ **Frontend** ขึ้นมาพร้อมกัน (ผ่านเครื่องมือที่ชื่อว่า concurrently):
- **หน้าเว็บ (Frontend):** เปิดดูได้ที่ `http://localhost:3000`
- **หลังบ้าน (API Server):** รันเปิดพอร์ตไว้ที่ `http://localhost:5001`
